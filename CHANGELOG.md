# Changelog

## 1.0.1 - 2026-11-18

- A refused key (HTTP 403) now names the reason the server gave, such as a CI key or a plan without the @font-face kit tool.

## 1.0.0 - 2026-11-18

- First release: builds WOFF2/WOFF files and an @font-face stylesheet from font sources with Everything Fonts.
- Optional subsetting with preset ids.
- Outputs `files` and `css-path`. The action never commits.
